# Libsic Studio music

These twelve short instrumental pieces were synthesized for this project using
sine waves, chord progressions and a seeded pseudo-random melody generator.
No recordings, samples or third-party compositions were used.

Generator: `docs/art-tools/make_music_tracks.py`, based on the team's
`make_test_tracks.py`. Rebuild with Python, numpy and ffmpeg:

```
python docs/art-tools/make_music_tracks.py client/public/audio/music
```

To the extent possible under law, the authors dedicate these generated audio
files to the public domain under **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

The existing rain ambience has its own credit in `../ambience/CREDITS.md`.
